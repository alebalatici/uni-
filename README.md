# Computer Science — Babeș-Bolyai University (UBB) 🎓💻

A structured collection of lecture notes, lab assignments, seminars, and projects completed during my **BSc in Computer Science** at **Babeș-Bolyai University (UBB), Cluj-Napoca**.

## 📚 Coursework Directory

### Year 1

#### Semester 1
* [Computer Systems Architecture](https://github.com/alebalatici/uni-/tree/main/year1/semester1/ComputerSystemsArchitecture) — Assembly (x86), CPU architecture, memory organization, and low-level operations.
* [Fundamentals of Programming](https://github.com/alebalatici/uni-/tree/main/year1/semester1/ProgrammingFundamentals) — Python, procedural & layered architecture, testing, and basic algorithms.

#### Semester 2
* [Object-Oriented Programming](https://github.com/alebalatici/uni-/tree/main/year1/semester2/ObjectOrientedProgramming) — C/C++, dynamic memory management, Qt GUI, and OOP design principles.
* [Data Structures and Algorithms](https://github.com/alebalatici/uni-/tree/main/year1/semester2/DataStructuresAndAlgorithms) — ADTs, complexity analysis, trees, hash tables, and efficient implementations in C++.
* [Operating Systems](https://github.com/alebalatici/uni-/tree/main/year1/semester2/OperatingSystems) — Linux shell scripting (Bash), processes, threads, pipes, and synchronization in C.
